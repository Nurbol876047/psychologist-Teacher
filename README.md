# Мұғалімге психологиялық қолдау

Веб-платформа с ИИ-психологом для учителей школ Казахстана: видео-ответы психолога на 10 типовых тем + свободный чат на базе OpenAI API. Интерфейс на казахском языке с переключением на русский.

## Стек

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS
- OpenAI API (`openai`, модель `gpt-4o-mini`) — только на сервере, через API routes
- Web Speech API — голосовой ввод (kk-KZ, с запасным вариантом ru-RU)

## Установка

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Создайте файл `.env.local` в корне проекта (по образцу `.env.local.example`) и впишите свой ключ OpenAI:

   ```
   OPENAI_API_KEY=ваш_ключ_openai
   ```

   Ключ получить можно на [platform.openai.com/api-keys](https://platform.openai.com/api-keys). Ключ используется только на сервере (в `app/api/classify` и `app/api/chat`) и никогда не попадает в браузер. Никогда не публикуйте и не коммитьте этот ключ — файл `.env.local` уже добавлен в `.gitignore`.

3. Положите фото психолога:

   ```
   public/psychologist.jpg
   ```

4. Положите 10 видео-ответов (ровно такие имена файлов):

   ```
   public/videos/01.mp4
   public/videos/02.mp4
   ...
   public/videos/10.mp4
   ```

   Соответствие тем видео — в файле [`data/topics.ts`](data/topics.ts).

5. Заполните тексты ответов для тем 2–10 в том же файле `data/topics.ts` (поля `response_kk` и `response_ru`). Тема 1 уже заполнена как образец. Пока поле пустое, платформа автоматически подставляет ответ, сгенерированный OpenAI, — видео при этом всё равно проигрывается.

6. Впишите актуальные номера телефонов доверия в [`config/help.ts`](config/help.ts) — они показываются, если в сообщении учителя обнаружены признаки кризисной ситуации.

## Запуск

Режим разработки:

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Продакшн-сборка:

```bash
npm run build
npm run start
```

```
app/                    страницы (Главная, Консультация, О проекте) и API routes

public/psychologist.jpg фото психолога (добавьте сами)
public/videos/          10 видео-ответов (добавьте сами)
```

## Как это работает

1. Учитель пишет вопрос (текстом или голосом).
2. Сначала идёт поиск по ключевым словам темы (без учёта регистра, с поддержкой казахских букв ә, ғ, қ, ң, ө, ұ, ү, һ, і).
3. Если совпадений нет — вопрос уходит на `/api/classify`, где OpenAI определяет наиболее подходящую из 10 тем (устойчиво к опечаткам, замене букв, другому языку и непрямым формулировкам).
4. Если тема найдена — проигрывается соответствующее видео и показывается заготовленный текст ответа.
5. Если тема не определена — OpenAI даёт короткий тёплый ответ текстом (без видео).
6. Если в сообщении обнаружены признаки кризисной ситуации (мысли о самоповреждении, суициде, насилии) — вместо обычного ответа сразу показывается блок с номерами телефонов доверия.

История чата хранится только в памяти текущей вкладки браузера (в состоянии React) — без базы данных и без сбора персональных данных. При обновлении страницы история очищается.
